# alu-back-end

Python scripts that gather data from the JSONPlaceholder REST API (https://jsonplaceholder.typicode.com).

## api

- `0-gather_data_from_an_API.py`: prints an employee TODO list progress
- `1-export_to_CSV.py`: exports an employee tasks to USER_ID.csv
- `2-export_to_JSON.py`: exports an employee tasks to USER_ID.json
- `3-dictionary_of_list_of_dictionaries.py`: exports all employees tasks to todo_all_employees.json
